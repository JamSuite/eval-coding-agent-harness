# Architecture decision records

One file per decision that shapes the harness and would be costly to reverse:
`NNNN-title.md`, numbered from `0001` in the order written. A record states the context, the
decision, what was observed or measured to support it, the alternatives rejected and why, and the
consequences.

A record is not edited to change its decision. A later decision supersedes it in a new record, and
the old one gains a line naming its successor. A small correction or a new observation that leaves
the decision standing is added as a dated amendment at the end.
